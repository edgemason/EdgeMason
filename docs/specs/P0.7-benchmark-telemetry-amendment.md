# Amendment: stabilise benchmark telemetry golden tests

**Applies to:** P0.7b (cases 15-16), P0.7c (cases 8-9)
**Status:** agreed (2026-10-15)

## Problem

Four test cases compare full benchmark output against a golden file. The
output includes live CPU measurements (throughput, latency percentiles,
memory RSS) that differ every run. The executor correctly stopped per the
spec's stop condition.

## Fix

In each of the 4 tests, before calling `assert_matches_golden`, replace
every nondeterministic measurement field with a placeholder string. Then
separately assert the original values are present and numeric.

### Step 1: add a helper to `tests/helpers.py`

```python
BENCHMARK_MEASUREMENT_KEYS = {
    "throughput_fps",
    "latency_p50_ms", "latency_p95_ms", "latency_min_ms", "latency_max_ms",
    "latency_mean_ms", "latency_std_ms",
    "total_time_ms",
    "fps",
    # memory — both naming conventions (QUIRK)
    "baseline", "peak", "delta",
    "baseline_mb", "peak_mb", "delta_mb",
    # estimates derived from measurements
    "estimated_latency_p50_ms", "estimated_memory_mb",
}


def strip_measurements(obj, *, _keys=BENCHMARK_MEASUREMENT_KEYS):
    """Deep-copy obj with live measurement values replaced by '<MEASUREMENT>'.

    Only replaces values whose key is in BENCHMARK_MEASUREMENT_KEYS and whose
    value is a number (int or float).  Everything else passes through unchanged.
    """
    if isinstance(obj, dict):
        return {
            k: ("<MEASUREMENT>" if k in _keys and isinstance(v, (int, float)) else strip_measurements(v))
            for k, v in obj.items()
        }
    if isinstance(obj, list):
        return [strip_measurements(item) for item in obj]
    return obj
```

### Step 2: fix the 4 tests

**P0.7b — `test_deploy_tiny_rpi4_cpu` and `test_deploy_tiny_rpi4_nocal`:**

```python
from tests.helpers import strip_measurements

# keep the original for type checks
original = response.json()

# golden locks structure + deterministic values
assert_matches_golden("deploy_tiny_rpi4_cpu", strip_measurements(normalise(original)))

# measurement fields exist and are positive numbers
for key in ("throughput_fps", "latency_p50_ms", "latency_p95_ms"):
    val = original["results"][0][key]  # adjust path to where the field lives
    assert isinstance(val, (int, float)) and val > 0, f"{key} = {val!r}"
```

Same pattern for the `_nocal` variant.

**P0.7c — `test_benchmark_isolated_format` and `test_benchmark_inprocess_format`:**

```python
from tests.helpers import strip_measurements

original = json.loads(stdout)  # or .to_dict()

assert_matches_golden("benchmark_isolated_format", strip_measurements(normalise(original)))

# measurement fields are present and numeric
assert isinstance(original["throughput"]["fps"], (int, float))
assert original["throughput"]["fps"] > 0
```

Same pattern for the in-process variant.

### Step 3: regenerate goldens

Delete the 4 affected golden files and run once so `assert_matches_golden`
recreates them with `<MEASUREMENT>` placeholders in place. Second run
passes. Third run passes (stable).

```bash
# P0.7b
rm tests/golden/deploy_tiny_rpi4_cpu.json tests/golden/deploy_tiny_rpi4_nocal.json
uv run pytest tests/test_characterize_http.py -k "rpi4" -q   # creates goldens, fails
uv run pytest tests/test_characterize_http.py -k "rpi4" -q   # passes
uv run pytest tests/test_characterize_http.py -k "rpi4" -q   # stable

# P0.7c

uv run pytest tests/test_characterize_optimizer.py -k "benchmark" -q  # stable
```
