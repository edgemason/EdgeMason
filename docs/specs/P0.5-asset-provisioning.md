**Depends on:** P0.4 (needs torch for model generation)
**Gate class:** identical (no product change)
**Status:** agreed (2026-10-15), ready for an executor
**Executor:** follow `docs/specs/EXECUTOR.md`.

## Base branch
```bash
git worktree add "../edgemason-P0.5" -b spec/P0.5 cleanup

BASE=$(git rev-parse HEAD)
```

## 1. Goal
The 9 models and 5 dataset files (~1.2 GB) are gitignored. A fresh sandbox can't get them. This spec writes a manifest (`assets.json`) and a script (`provision_assets.py`) so any machine can provision itself and verify it has the right files.

**Verification method (decided by the user):**
- **Models:** output equivalence within 1e-5 (not byte-identical sha256). A seeded input is run through both the reference and the provisioned model; the max absolute difference must be ≤ 1e-5.
- **Datasets:** output equivalence. Labels must be identical; image data must match within 1e-5. Row order doesn't matter.
- **EfficientNet B0** is added as a new model, generated from torchvision like mobilenetv2.

**Done means:** `provision_assets.py` provisions every asset into a fresh worktree, verifies each one, and all tests pass.

### Reference outputs
Before provisioning can verify by output equivalence, reference outputs must exist. These are small `.npz` files (one per model) containing the output of running the reference model on a seeded input (`np.random.default_rng(0)`, the model's input shape, float32) on `CPUExecutionProvider`.

They live in `assets/reference/` and are committed to git (they're small — a few KB each). The provisioning script generates them from the user's current models the first time, using the environment variable `EDGEMASON_REFERENCE_ASSETS` (path to the repo with the original models). After that they're in git and no variable is needed.

### `scripts/provision_assets.py`
```
uv run python scripts/provision_assets.py [--dest DIR] [--only GLOB ...] [--verify-only] [--manifest assets.json]
```
- **`--dest`** defaults to the repo root. Asset paths resolve relative to it.
- **Idempotent.** If a file exists and verifies, skip it and print `ok <path>`.
- **Never overwrites a file that fails verification.** Prints `MISMATCH <path>` and exits with code 2.
- **Missing files** are produced from `source`, in dependency order (a `convert` asset waits for its `from` asset).
- **`--verify-only`** produces nothing. Exit 0 = all verified; 2 = mismatch; 3 = files missing.
- **`--only GLOB`** filters which assets to touch.

**Out of scope:**
- Changing `scripts/prepare_imagenetv2_subset.py` or `scripts/download_imagenetv2_large.py`. Call them as subprocesses.
- Changing any file under `api/`, `frontend/`, `profiles/`, `reports/`
- Changing any existing test

## 5. Failures

| If | Then |
|---|---|
| A Model Zoo URL no longer serves the file (404 or different content) | **Stop and report.** Don't substitute another source. |
| Hugging Face returns different data than the script expects | **Stop and report.** |
| EfficientNet B0 export fails or produces a model that doesn't run on CPUExecutionProvider | **Stop and report.** Don't change the export code beyond following the existing pattern. |
| Output equivalence fails for a model at 1e-5 (the provisioned model differs too much from reference) | **Stop and report** the max absolute difference. Don't loosen the tolerance. |
| `model_generators.py` changes break the existing 4 tests in `test_model_generators.py` | **Stop and report.** |
| Any file outside Scope needs changing | **Stop and report.** |
