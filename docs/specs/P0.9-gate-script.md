# P0.9: The results gate

**Depends on:** P0.8. For lint/types it uses P0.10 if merged; otherwise skips those checks and says so.
**Gate class:** identical (tooling only)
**Status:** agreed (2026-10-16), ready for an executor
**Executor:** follow `docs/specs/EXECUTOR.md`.

## Base branch
```bash
git worktree add "../edgemason-P0.9" -b spec/P0.9 cleanup
cd "../edgemason-P0.9"
BASE=$(git rev-parse HEAD)
```

## 1. Goal
Every later spec is adopted only if "results match or beat the baseline". This spec turns that agreed rule into a command with exit code 0 or 1, so no agent and no tired human has to judge it by eye.

The agreed gate:

| Output | Rule |
|---|---|
| Deterministic outputs (`baseline/` files, goldens) | identical |
| Accuracy | identical within 1e-6 |
| Timing and memory | alternating A/B runs in the same session; same winner; p50 within noise band |
| Tests, lint, types | all pass, no deleted tests |

## 2. Schema

### CLI
```
uv run python scripts/gate.py check  --candidate PATH [--level fast|full] [--baseline-dir baseline] [--report OUT.json]
uv run python scripts/gate.py ab     --baseline PATH --candidate PATH [--models NAME ...] [--rounds 5] [--report OUT.json]
```

`PATH` arguments are git worktree roots. The gate never modifies either tree. It only runs commands inside them, and only `provision_assets.py --dest <tree>` writes there, into that tree's own `models/`.

### `check` steps (stop at first failure)

1. **Assets.** `provision_assets.py --dest <candidate> --verify-only`. If files are missing, provision them, then verify again.
2. **Tests.**
   - `fast`: `pytest -m "not slow and not tvm and not cuda and not research"`
   - `full`: `pytest`

   Then compare collected test node ids with the baseline tree's (`pytest --co -q` in both). **Any id that exists in baseline but not in candidate is a failure.** Exception: ids listed via `--allow-deleted FILE` (one node id per line).
3. **Goldens.** `git -C <candidate> diff --name-only <merge-base> -- tests/golden baseline` must be empty, unless `--allow-golden-change` is passed. That flag is only for specs the user has approved.
4. **Deterministic outputs.** Run `capture_baseline.py` in the candidate (`--quick` for fast, default for full) into a temp dir. Diff against `baseline/quick` or `baseline/full`:
   - All files except `environment.json` and `accuracy.json`: byte-identical
   - `accuracy.json`: equal within 1e-6 per number
5. **Lint and types.** If P0.10 has merged, run its ratchet command. Otherwise record `skipped`.

### `ab` protocol

- **Runs.** For each model (default: `squeezenet1.1-13`, `mobilenetv2`, `resnet50`) and each candidate variant (fp32, dynamic, static), run `rounds` rounds of alternating benchmarks: B, C, B, C, …
  - Each run uses its own tree's `api.optimizer.benchmark_engine.benchmark(…, isolated=True)` with product defaults from that tree's `api/config.py`
  - Each run invoked as a subprocess with `cwd=<tree>`
- **Pass rules, per model × variant:**
  - Let `mB` and `mC` = medians of the p50 values, and `MAD_B` = median absolute deviation of baseline p50s
  - **Pass** if `|mC − mB| ≤ max(2·MAD_B, 0.05·mB)`
  - Same rule applies to `memory_mb.delta`
- **Winner.** Per model, the variant with the lowest median p50 must be the same in B and C.

### Report format

- **`--report` JSON:** `{ "verdict": "pass"|"fail", "steps": [{"name", "status", "details"}], "ab": {...} }`
- **stdout:** a short markdown summary
- **Exit code:** 0 = pass, 1 = fail, 2 = usage/environment error

## 3. Scope

**May create or change:**
- `scripts/gate.py` (new)
- `tests/test_gate.py` (new)
- `docs/specs/GATE.md` (new; how to run the gate and read its report)

**Out of scope (do not touch, even if tempting):**
- `baseline/`, `tests/golden/`, `api/` or any existing script
- Any existing test file

## 5. Failures

| If | Then |
|---|---|
| Self-test A/B fails (noise exceeds 5% with nothing changed) | **Stop and report** the numbers. The threshold is the user's decision. |
| A mutation test passes (gate is blind) | **Stop and report** which one. |
| `capture_baseline.py` fails in the candidate tree | **Stop and report.** Likely a P0.8 issue. |
| Any file outside Scope needs changing | **Stop and report.** |
