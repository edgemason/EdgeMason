# P1.1: Remove the `onnx_runtime.py` shim

**Backlog:** B-06 (first half: delete the file; returning data instead of JSON strings is out of scope)
**Depends on:** PR #1 (`cleanup` → `main`) merged, so the worktree branches from a `main` that has Phase 0
**Gate class:** identical
**Status:** agreed
**Executor:** follow `docs/specs/EXECUTOR.md` (its absolute limits always apply).

## 1. Goal

`api/optimizer/onnx_runtime.py` is a pass-through. Its only live function, `benchmark()`, forwards
every argument to `api.optimizer.benchmark_engine.benchmark()` and returns the result unchanged. The
other four functions (`benchmark_tvm`, `inference_session`, `make_input`, `run_inference`) are
dead: nothing outside the file calls them, and the branch inside `benchmark()` that would call two of
them needs `sample_path`, which no caller passes.

Done means: the file no longer exists, `api/services/pipeline.py` imports `benchmark` straight from
`api.optimizer.benchmark_engine`, and the gate reports results identical to the baseline.

## 2. Schema

`api/services/pipeline.py`, line 17:

```python
# before
from api.optimizer.onnx_runtime import benchmark
# after
from api.optimizer.benchmark_engine import benchmark
```

Nothing else in `pipeline.py` changes. The call at `pipeline.py:85-93` already passes only
arguments that `benchmark_engine.benchmark()` accepts under the same names.

`README.md`, line 61 (project structure tree):

```text
# before
│   │   ├── onnx_runtime.py         # inference sessions + latency/memory benchmark
# after
│   │   ├── benchmark_engine.py     # latency/memory/throughput benchmark (ONNX Runtime + TVM)
```

- Any test file. No test imports `onnx_runtime`, so none needs to change.

`--level full`, not `fast`: fast skips the slow, TVM and research tests and checks only two quick
models. `pipeline.py` is on the path of every deploy, so every model is checked.

before the benchmark subprocess starts. Timing happens inside `_run_timed` in that subprocess, so the
change is outside the measured region and cannot move p50 or memory.
