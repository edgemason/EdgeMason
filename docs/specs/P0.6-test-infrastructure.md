# P0.6: Test infrastructure (markers, timeout, seeds, normaliser)

**Depends on:** P0.4 (pytest-timeout and mutmut already installed)
**Gate class:** identical (product code untouched)
**Status:** agreed (2026-10-14), ready for an executor
**Executor:** follow `docs/specs/EXECUTOR.md`.

## Base branch
```bash
git worktree add "../edgemason-P0.6" -b spec/P0.6 cleanup
cd "../edgemason-P0.6"
BASE=$(git rev-parse HEAD)
```

## 1. Goal
Tests today have four problems:
- No way to run just the fast tests (no markers).
- A hanging test blocks forever (no timeout).
- Random numbers change every run (unseeded RNG).
- Outputs contain paths, UUIDs, timestamps and versions that differ between runs (no normaliser).

**Done means:** every test is marked, tests time out after a fixed limit, all RNG is seeded, and a normaliser in `tests/helpers.py` strips run-specific noise so outputs are comparable.

## 2. Schema

### pytest config (`pyproject.toml`)
```toml
[tool.pytest.ini_options]
testpaths = ["tests"]
pythonpath = ["."]
timeout = 60
markers = [
    "slow: takes >10s or uses real models",
    "tvm: needs apache-tvm",
    "research: needs the research dependency group (torch/torchvision)",
]
```
- **Fast gate:** `uv run pytest -m "not slow and not tvm and not research" -q`
- **Full gate:** `uv run pytest -q`

### Seed fixture (`tests/conftest.py`)
An autouse, function-scoped fixture that runs before every test:
```python
@pytest.fixture(autouse=True)
def _seed_rng():
    import random
    import numpy as np
    random.seed(42)
    np.random.seed(42)
```
This controls test-level randomness only. Product code is not changed.

### Normaliser (`tests/helpers.py`, new file)
```python
def normalise(obj):
    """Deep-copy obj with run-specific values replaced by placeholders."""
```
Replacement rules, applied recursively over dicts, lists and strings:

| Pattern | Replacement |
|---|---|
| Absolute filesystem path (starts with `/` or contains a system temp dir) | `<PATH>` |
| UUID (32 hex chars, with or without dashes) | `<UUID>` |
| Value under a key named `system_info` | `<SYSTEM_INFO>` |
| Package version string like `name==X.Y.Z` | `<VERSION>` |
| ISO timestamp (`YYYY-MM-DDTHH:MM:SS...`) | `<TIMESTAMP>` |

### Markers to apply
- `research`: `test_model_generators.py` — use `pytestmark = [pytest.mark.research]` at module level. Remove `pytest.importorskip("torch")` since torch is now always installed.
- `slow` and `tvm`: none to apply today. The markers are registered so P0.7 can use them.

## 3. Scope

**May create or change:**
- `pyproject.toml` — only `[tool.pytest.ini_options]`
- `tests/conftest.py` — add the seed fixture
- `tests/helpers.py` — new file, the normaliser
- `tests/test_helpers.py` — new file, tests for the normaliser
- `tests/test_model_generators.py` — add `research` marker, remove `importorskip`

**Out of scope:**
- Any file under `api/`, `scripts/`, `frontend/`, `profiles/`, `reports/`
- Writing new tests beyond `test_helpers.py` (that's P0.7)
- Changing what any existing test asserts
- Changing `uv.lock` (dependencies already installed from P0.4)

## 5. Failures

| If | Then |
|---|---|
| The seed fixture changes test results (a test that passed now fails, or vice versa) | **Stop and report.** That test depends on unseeded randomness, which is a finding. Don't fix the test. |
| `pytest --strict-markers` fails because an existing test uses an unregistered marker | **Stop and report.** Don't add the marker without checking it belongs to our three. |
| Removing `importorskip` from `test_model_generators.py` causes failures | **Stop and report.** Don't edit the tests beyond removing the skip and adding the marker. |
| The normaliser can't handle some edge case in existing test outputs | That's fine for now — it gets extended in P0.7/P0.8. Only the five patterns listed are required. |
| Any file outside Scope needs changing | **Stop and report.** |
