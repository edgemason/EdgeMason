# P0.7c: Characterization tests for quantization, benchmark format and packaging

**Depends on:** P0.6
**Gate class:** identical (tests only; they lock current behaviour)
**Executor:** follow `docs/specs/EXECUTOR.md`.

## Why
These settings are research-sensitive (PLAN C), but today they are checked only loosely:
- static INT8 is QInt8, per-channel, and runs `quant_pre_process` first
- dynamic INT8 uses QUInt8
- the format of the benchmark result, including the memory-key mismatch
- the contents of the deployment ZIP

A refactor that silently changed any of these would invalidate the paper's numbers.

## Scope (new test file only)
- `tests/test_characterize_optimizer.py`
- `tests/golden/*.json` created by it

## Out of scope
- Any change to `api/`. Lock quirks with a `# QUIRK:` comment.

## Test cases

### Quantizer (`api.optimizer.quantizer.Quantizer`)
Use a tiny Conv model: input `[1, 3, 8, 8]`, one Conv with 4 output channels and seeded weights, then Relu, opset 13. Use calibration data `seeded_rng.random((8, 3, 8, 8), dtype=np.float32)`.

| # | Given | Then |
|---|---|---|
| 1 | `create_static_int8` | Load the output model. Assert:<ul><li>the Conv weight's DequantizeLinear chain uses an **int8** zero-point tensor (QInt8, not uint8);</li><li>the weight scale has **4 elements** (per-channel), with `axis=0`;</li><li>the activation zero-point is int8 (S8S8).</li></ul>Golden `static_int8_tiny_conv` holds the sorted list of `op_type`s and the initializer names, dtypes and shapes. |
| 2 | Spy on `quant_pre_process` (monkeypatch it in the quantizer module with a wrapper that records the call, then delegates) | it is called exactly once with `skip_symbolic_shape=True` |
| 3 | `quant_pre_process` monkeypatched to raise `RuntimeError` | `create_static_int8` still produces a valid model (# QUIRK: silent fallback) |
| 4 | `create_dynamic_int8` on the tiny MatMul model `tiny_onnx` | the weight is quantized as **uint8** (QUInt8). Golden `dynamic_int8_tiny` holds the op types plus the initializer dtypes. |
| 5 | `create_fp32` | the output file bytes equal the input file bytes, or lock what differs |
| 6 | `quantize_for_candidate` with each of `onnx_fp32_baseline`, `onnx_dynamic_int8`, `onnx_static_int8` (with calibration), `onnx_static_int8` (without), and `bogus` | lock: the file suffix, or the exact `ValueError` message |
| 7 | **Determinism:** `create_static_int8` twice in fresh output dirs | the two outputs are **byte-identical**. If they are not, lock that they differ, mark `# QUIRK`, and report it, because the gate design depends on this. |
