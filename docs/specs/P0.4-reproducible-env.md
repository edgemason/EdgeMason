## 1. Goal
- **For whom:** isolated sandboxes and worktrees used for the codebase cleanup. Not end-user packaging.
- **Machines:** Fedora (the user's laptop, which has an RTX 4050) and Ubuntu 24.04. Target devices come later.
- **TVM:** pinned to 0.26.0 and installed by default. It is kept for later use.
- **Done means:** in a fresh clone, `uv sync` alone, then `uv run pytest -q`, gives **the base's passed count + 4, and 0 skipped**. The 4 are the generator tests that torch unblocks.

## 2. Schema
`pyproject.toml`:
```toml
dependencies = [
    # …every existing line unchanged, except:
    "apache-tvm==0.26.0",

[dependency-groups]
dev = ["pytest", "pytest-timeout", "mutmut"]

[tool.uv]

[[tool.uv.index]]

[tool.uv.sources]

```
- **`.python-version`** (new) contains exactly `3.11`.
- **`requirements.txt`:** `apache-tvm` becomes `apache-tvm==0.26.0`. No other change.
- **`tests/test_env_consistency.py`** (new) asserts that the runtime dependencies in `pyproject.toml` and the requirement lines in `requirements.txt` are the **same set**. Before comparing, it normalises quote style (`'` vs `"`) and whitespace, and it ignores comments and blank lines. Read `pyproject.toml` with `tomllib`.
- **`README.md`:** the Python line reads `>=3.11,<3.12`. The setup section says the single command is `uv sync`, which installs the product, dev and research groups, with CPU-only torch.

## 3. Scope
**May create or change only:**
- `pyproject.toml`
- `uv.lock` (only via `uv lock` or `uv sync`; never hand-edited)
- `.python-version`
- `requirements.txt` (the TVM line only)
- `README.md` (the Python-version line and the setup section only)
- `tests/test_env_consistency.py`

**Out of scope:**
- Removing any dependency, tensorflow and keras included.
- Changing any version that is already pinned.
- The empty root `Dockerfile`.
- Making TVM opt-in.
- Anything under `api/`, `scripts/`, `models/`, `frontend/`, `profiles/` or `reports/`.

## 4. Behaviour: tasks (one small commit each; stop after any failing check)

Every task ends by running its check and committing. Commit messages are `P0.4 Tn: <title>`.

**T1: Record the base** (no commit)
```bash
uv sync && uv run pytest -q 2>&1 | tail -1     # write down "N passed, M skipped" as the base counts
```

**T2: Consistency test (lock it in, then prove it can fail)**
1. Write `tests/test_env_consistency.py`. Run it. It must **pass**: both files currently list `apache-tvm` unpinned.
2. Prove it can fail: temporarily change `pillow==12.3.0` to `pillow==12.3.1` in `requirements.txt`. The test must **fail**. Revert the change; the test passes again.
3. Commit the test only.

**T3: Pin TVM and Python**
- Add `.python-version`. Pin `apache-tvm==0.26.0` in **both** `pyproject.toml` and `requirements.txt`. Run `uv lock`.
- Check: the lock check (below) passes, the consistency test passes, and `uv run pytest -q` matches the base counts.

**T4: Dev group**
- Add `pytest-timeout` and `mutmut` to `dev`. Run `uv lock`.
- Check: the lock check passes, and `uv run python -c "import pytest_timeout, mutmut"` succeeds.

**T5: Research group with CPU torch**
- Add the `research` group, `default-groups`, the `pytorch-cpu` index and `[tool.uv.sources]`, exactly as in the Schema. Run `uv lock`, then `uv sync`.
- Checks:

  | # | Command | Expected |
  |---|---|---|
  | a | `uv run python -c "import tvm; print(tvm.__version__)"` | `0.26.0` |
  | b | `uv run python -c "import torch; print(torch.version.cuda)"` | `None` |
  | c | `uv run python -c "import onnxruntime as o; print(o.get_available_providers())"` | includes `CUDAExecutionProvider` (on Fedora) |
  | d | `uv run pytest -q` | base passed + 4, **0 skipped** |
  | e | the lock check | passes |

**T6: README** (the two places in Schema only). Check: `git diff --stat` shows only `README.md` for this commit.

**T7: Ubuntu proof in a container** (no commit). Run this from the worktree root. It copies the tree into the container, so nothing in the worktree is touched:
```bash
podman run --rm --security-opt label=disable -v "$PWD":/src:ro ubuntu:24.04 bash -c '
  apt-get update -qq && apt-get install -y -qq curl ca-certificates >/dev/null &&
  curl -LsSf https://astral.sh/uv/install.sh | sh >/dev/null && export PATH=$HOME/.local/bin:$PATH &&
  mkdir /work && tar --exclude=.venv --exclude=.git -C /src -cf - . | tar -C /work -xf - && cd /work &&
  uv sync --frozen && uv run python -c "import tvm, torch; print(tvm.__version__, torch.version.cuda)" &&
  uv run pytest -q 2>&1 | tail -1'
```
Expected: `0.26.0 None`, then the same counts as T5 d. The container has no GPU, so if the counts differ, list the differing test ids. Don't fix anything.

**Lock check** (used in T3–T5): no package that was in the base lock may change version or disappear.
```bash
uv run python - "$BASE" <<'EOF'
import subprocess, sys, tomllib
old = tomllib.loads(subprocess.check_output(["git", "show", f"{sys.argv[1]}:uv.lock"], text=True))
new = tomllib.load(open("uv.lock", "rb"))
pairs = lambda lock: {(p["name"], p.get("version")) for p in lock["package"]}
lost = sorted(pairs(old) - pairs(new))
print("added:", len(pairs(new) - pairs(old)), "| changed or removed:", lost)
sys.exit(1 if lost else 0)
EOF
```

**Final acceptance:**
```bash
uv lock --check
uv run pytest -q                       # base passed + 4, 0 skipped
git diff --name-only "$BASE"           # only files listed in Scope
```

**Tests that may be deleted:** none.

## 5. Failures (stop and report; do not work around)
| If | Then |
|---|---|
| The lock check lists any changed or removed package (for example, torch forcing a newer numpy or protobuf) | **Stop.** Report each package and its old and new version. Don't add constraints or overrides on your own. |
| `uv lock` can't resolve, for example a platform the CPU index lacks | **Stop.** Report the full error. Don't add `environments` or markers to work around it. |
| Check b shows a CUDA version (torch came from PyPI, not the CPU index) | Recheck `[tool.uv.sources]` against the Schema once. If it still fails, stop and report. |
| Check c no longer lists `CUDAExecutionProvider` after T5 | **Stop.** Torch may be clashing with onnxruntime-gpu's CUDA libraries. Report the `uv pip list` lines for `nvidia-*`. |
| The generator tests fail (not skip) once torch is installed | **Stop.** Report the failure. Don't edit the test or `models/model_generators.py`. |
| T7's counts differ from Fedora's | Report the differing test ids. Don't fix anything. |
| Anything requires touching a file outside Scope | **Stop** and report. |
