# P0.10: Lint, types and CI (with a ratchet)

**Depends on:** P0.6 (markers for the fast test run)
**Gate class:** identical (config and CI only)
**Status:** agreed (2026-10-15), ready for an executor
**Executor:** follow `docs/specs/EXECUTOR.md`.

## Base branch
```bash
git worktree add "../edgemason-P0.10" -b spec/P0.10 cleanup
cd "../edgemason-P0.10"
BASE=$(git rev-parse HEAD)
```

## 1. Goal
`CODING_STANDARDS.md` rule 12 says new code passes ruff and pyright. The existing code would fail a strict configuration, and fixing all of it now would be a giant unreviewable diff. A **ratchet** solves this:
- a minimal, must-pass rule set on the whole repo (real bugs only);
- the full rule set on files a branch **adds**.

CI runs the fast gate on every push, so a broken `cleanup` is caught immediately.

## 2. Schema

### Config (`pyproject.toml`)
- **ruff:**
  - `target-version = "py311"`, `line-length = 100`
  - **Whole repo (minimal):** `ruff check --select E9,F63,F7,F82 .` — syntax errors and undefined names
  - **New files (full):** `ruff check --select E,F,W,I,B,UP,SIM` on the files listed by `git diff --name-only --diff-filter=A $BASE_REF...HEAD -- '*.py'`
- **pyright:** `typeCheckingMode = "basic"`, `pythonVersion = "3.11"`, run **only** on the new files
- Add `ruff` and `pyright` to the `dev` dependency group

### `scripts/lint_ratchet.sh`
- Runs both ruff tiers and pyright on the new files
- Takes the base ref from `$BASE_REF`, defaulting to `origin/cleanup`
- Exits non-zero on any finding
- Is a no-op success when no `.py` file was added

### `.github/workflows/ci.yml`
- On `push` and `pull_request`
- `ubuntu-latest`, `astral-sh/setup-uv` (pin a version tag), Python 3.11
- `uv sync --group dev`
- `scripts/lint_ratchet.sh` with `BASE_REF=origin/${{ github.base_ref || 'cleanup' }}`
- Uses `fetch-depth: 0` so the full history is available for the diff
- `uv run pytest -q -m "not slow and not tvm and not research"`
- Cache uv

**Important:** Run all checks locally first. Only push to trigger CI after the local run passes.

## 3. Scope

**May create or change:**
- `pyproject.toml`: `[tool.ruff]`, `[tool.ruff.lint]`, `[tool.pyright]`; add `ruff` and `pyright` to the `dev` group
- `uv.lock` (via `uv lock` only)
- `scripts/lint_ratchet.sh` (new)
- `.github/workflows/ci.yml` (new)

**Out of scope:**
- **Fixing lint findings in existing code.** If the minimal set fails on existing code, stop: see Failures.
- `ruff format`: no reformatting of existing files.
- Any file under `api/`, `frontend/`, `profiles/`, `reports/`

## 4. Behaviour (tasks)

**T1: Add ruff and pyright config to `pyproject.toml`, add to dev group, lock**

Check: `uv lock --check` passes; `uv run ruff check --select E9,F63,F7,F82 .` exits 0.

Commit: `P0.10 T1: ruff and pyright config`

**T2: Write `scripts/lint_ratchet.sh`**

Check:
1. On a scratch branch that adds `tmp_ratchet_probe.py` containing `import os` (unused): `scripts/lint_ratchet.sh` exits non-zero (F401). Delete the probe; don't commit it.
2. Same probe, with a modified existing file that has old violations: the ratchet only flags the new file.
3. No `.py` files added: exits 0.

Commit: `P0.10 T2: lint ratchet script`

**T3: Write `.github/workflows/ci.yml`**

Run the workflow steps locally:
```bash
uv sync --group dev
BASE_REF=cleanup scripts/lint_ratchet.sh
uv run pytest -q -m "not slow and not tvm and not research"
```

If the user allows a push, push the branch and report the CI run URL. Otherwise report the local results.

Commit: `P0.10 T3: CI workflow`

**Final acceptance:**
```bash
uv lock --check
uv run ruff check --select E9,F63,F7,F82 .
BASE_REF=cleanup scripts/lint_ratchet.sh
uv run pytest -q -m "not slow and not tvm and not research"
uv run pytest -q                                            # full suite, no regressions
git diff --name-only "$BASE"                                # only files in Scope
```

## 5. Failures

| If | Then |
|---|---|
| The minimal rule set fails on existing code (real undefined name or syntax error) | **Stop and report.** List them. They become backlog bugs. Don't fix. |
| `uv lock` changes any existing package version | **Stop and report.** |
| Any file outside Scope needs changing | **Stop and report.** |

## Rollback
```bash
git worktree remove --force "../edgemason-P0.10" && git branch -D spec/P0.10
```
