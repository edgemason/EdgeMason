**Depends on:** P0.6, P0.7a (uses `assert_matches_golden` from `tests/helpers.py`)
**Gate class:** identical (tests only; they lock current behaviour)
**Status:** agreed (2026-10-15), ready for an executor
**Executor:** follow `docs/specs/EXECUTOR.md`.

## Base branch
```bash
git worktree add "../edgemason-P0.7b" -b spec/P0.7b cleanup
cd "../edgemason-P0.7b"
BASE=$(git rev-parse HEAD)
```
**Note:** if P0.7a hasn't merged yet, cherry-pick its T0 commit (the golden helper) before starting. Or wait for it to merge.

## 1. Goal
`/analyze` has no test. `/deploy` has one happy-path test. Upload limits, validation errors, artifact expiry and bad download IDs are untested. Lock all of these so a refactor can't silently break the API contract.

## 2. Schema

### Test file
`tests/test_characterize_http.py` with golden files in `tests/golden/`.

Copy the client setup from `tests/test_api.py`:
- `httpx.AsyncClient(transport=httpx.ASGITransport(app=app), base_url="http://test")`
- `@pytest.mark.anyio`
- the local `anyio_backend` fixture returning `"asyncio"`

Use the `tiny_onnx` fixture. Mark a test `@pytest.mark.slow` only if it runs the real deploy pipeline.

## 3. Scope

**May create or change:**
- `tests/test_characterize_http.py` (new)
- `tests/golden/*.json` (new)

**Out of scope:**
- Any file under `api/`, `scripts/`, `frontend/`, `profiles/`, `reports/`
- `tests/helpers.py` (already has what's needed from P0.7a)
- Changing any existing test

## 4. Behaviour (tasks)

**T1: `/analyze` and `/deploy` validation tests**
Cases 1–14.
Check: first run creates goldens (fails), second passes.
Commit: `P0.7b T1: analyze and deploy validation characterization`

**T2: Full deploy, artifacts and pages**
Cases 15–22. Mark 15 and 16 `@pytest.mark.slow`.
Check: first run creates goldens, second passes, third passes (stable).
Commit: `P0.7b T2: deploy response, artifacts and pages characterization`

**Final acceptance:**
```bash
uv run pytest -q tests/test_characterize_http.py    # passes
uv run pytest -q tests/test_characterize_http.py    # stable
uv run pytest -q                                     # no regressions
git diff --name-only "$BASE"                         # only files in Scope
```
